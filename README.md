# TrendFish 2026

**Drivers, Trends, and Signals in Fisheries Research: A Structured Literature Review and Horizon Scan**

*Timo Szczepanska — Norwegian College of Fishery Science, UiT The Arctic University of Norway*
*Target journal: Reviews in Fish Biology and Fisheries*

---

## Overview

This repository contains the data, analysis scripts, and manuscript generation pipeline for a three-step horizon scanning and structured literature review that maps the drivers, trends, and weak signals shaping the future of fisheries. The central finding is a +28 percentage-point gap in technological driver coverage between cross-sectoral foresight literature and fisheries-specific futures research.

### Three-step search strategy

| Step | Description | n |
|------|-------------|---|
| 1 | Structured review of peer-reviewed fisheries futures literature (OpenAlex) | 60 manual + 720 pending |
| 2 | Cross-sectoral scan of megatrend foresight publications | 145 |
| 3 | Horizon scan for weak and emerging signals (living document) | ongoing |

All sources are classified using the **STEEP framework** (Social, Technological, Economic, Environmental, Political).

## Getting started

### Prerequisites

Python 3.11+ is recommended.

```bash
pip install -r requirements.txt
```

### Running the review app

The Streamlit app is the primary tool for managing the entire literature review workflow:

```bash
python -m streamlit run analysis/review_app.py
```

The app has six tabs:

| Tab | Purpose |
|-----|---------|
| 🔍 Search | Query OpenAlex, build boolean search strings, add papers to the review pool |
| 📄 Review | Paper-by-paper screening with keyword scoring and verdict buttons |
| 🌍 Megatrends | Browse and add to the cross-sectoral megatrend database (Strategy 2) |
| 📡 Signals | Document weak and emerging signals (Strategy 3) |
| 📊 Analysis | STEEP gap analysis, PRISMA counts, review progress |
| ⚙️ Keywords | Configure keyword lists for automated pre-screening |

### Data files

| File | Description |
|------|-------------|
| `data/manual_literature_search.xlsx` | Master database: megatrends, fisheries futures, signals (Excel) |
| `data/full_text_review.csv` | Review pool — 720 papers from OpenAlex, with verdicts |
| `data/review_keywords.json` | Keyword lists for automated scoring (editable in app) |
| `data/search_config.json` | Saved search queries and settings |
| `data/signals.json` | Weak signals database (managed via 📡 Signals tab) |

## Manuscript pipeline

Individual sections are generated by the `write_*.py` scripts and merged into a single Word document:

```bash
python analysis/write_methods.py
python analysis/write_results.py
# ... other sections
python analysis/merge_manuscript.py   # → docs/Manuscript_Trends_2026.docx
```

### AI peer review

To run an independent AI review of the current manuscript draft:

```bash
# Create a .env file with your Anthropic API key:
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env

python analysis/review_agent.py
# → docs/Review_Trends_2026.md
# → docs/Review_Trends_2026.docx
```

## PRISMA compliance

The search strategy follows [PRISMA 2020 reporting guidelines](https://www.prisma-statement.org/) (Page et al., 2021). The flow diagram is generated by:

```bash
python analysis/generate_prisma.py   # → docs/PRISMA_flow.svg / .png
```
